Case Study

Sala "Pałac pod Dębami" × Kasia i Tomek
Pełny scenariusz: od rejestracji sali po rozliczenie wesela

Bohaterowie

Ania — managerka sali weselnej "Pałac pod Dębami" (120–200 gości, 3 sale, 3 pakiety menu)

Kasia i Tomek — para młoda (ślub 15 sierpnia 2026, 95 gości)

FAZA 1 — Onboarding sali (Dzień 1)

Ania wchodzi na WeddingBoard → klika "Jestem Organizatorem" → rejestruje się przez email + Google → wypełnia onboarding:

  • Nazwa: "Pałac pod Dębami"
  • Adres, email, telefon, maksymalna pojemność: 200 gości
  • System tworzy profil sali z unikalnym slugiem
  • Przekierowanie na dashboard managera

FAZA 3 — Pierwsza rezerwacja (Tydzień 2)

Dashboard → "+ Nowa rezerwacja":

  • Imiona: Kasia i Tomek | Email: kasia@example.com
  • Data: 15.08.2026 | Sala: Oranżeria | Pakiet: Premium
  • Goście (szac.): 100 → system: 100 × 240 zł = 24 000 zł
  • Send invite: wysyła link z tokenem do pary

FAZA 4 — Portal pary młodej

Aktywacja: Kasia klika link → widzi powitanie → "Potwierdzam" → status ACTIVE

Zakładka ① — Lista gości

  • Ręcznie: imię, nazwisko, dieta (wege/vegan/dziecko), alergie, grupa
  • CSV import: plik 40-gości-od-rodzicow.csv → system parsuje i dodaje
  • Łącznie: 95 gości (3 wege, 2 vegan, 4 dzieci)
  • "Przekaż listę sali" → guestsCompleted = true

Zakładka ② — Menu

  • Wybiera: rosół, łosoś, tiramisu z pakietu Premium
  • System: 95 × 240 zł = 22 800 zł szacunkowo
  • "Zatwierdź menu" → menuCompleted = true

Zakładka ③ — Usadzenie

  • Widzi 20 stołów × 10 os. z kontrolą pojemności
  • Przypisuje gości → stół nr 5: 11 osób → ⚠ czerwone ostrzeżenie
  • Koryguje → "Przekaż usadzenie sali" → seatingCompleted = true

Zakładka ④ — Harmonogram

  • "Szablon wesela" → ładuje 9-punktowy timeline
  • Dostosowuje godziny → "Przekaż harmonogram" → scheduleCompleted = true

Zakładka ⑤ — Wiadomości (czat)

  • Kasia: "Czy możemy dostać dodatkowy stół dla dzieci?"
  • Ania (sala): "Tak, przygotujemy obok stołu nr 3"

FAZA 8 — Dzień wesela

Checklisty dla załogi:

  • Kuchnia: rosół 95 porcji ✓, łosoś 93 porcje ✓, tiramisu ✓, tort ✓
  • Serwis: lista stołów z gośćmi i alergiami (⚠ Anna K. — orzechy, stół 5)
  • Manager: harmonogram 15:00–01:00 godzinowy

PDF export: lista gości, plan stołów, harmonogram, plan sali.

FAZA 9 — Po weselu

  • Ostatnia rata oznaczona jako opłacona
  • Kaucja zwrócona → status zmieniony
  • Rezerwacja → COMPLETED
  • Raporty: Premium = 70% rezerwacji → Ania podnosi cenę do 260 zł
