# Archiwum — WeddingBoard

Dokumenty z czasów poprzedniego produktu (panel pary młodej, marketplace, RSVP,
płatności Stripe, logowanie przez Clerk). **Żadna z opisanych tu rzeczy nie
odzwierciedla dzisiejszego EventBoarda:**

- logowanie jest własne (e-mail + hasło, podpisany token w cookie), Clerk nie jest używany,
- płatności są ręczne — faktura poza systemem, status opłacenia ustawia administrator,
- nie ma publicznej rejestracji; przestrzenie zakłada administrator platformy.

Trzymamy je, bo opisują decyzje i migracje, które mogą się przydać przy archeologii
(np. „dlaczego ta kolumna tak się nazywa"). Przy szukaniu instrukcji dla bieżącego
produktu zaczynaj od [CLAUDE.md](../../CLAUDE.md), [PLAN-NAPRAWY.md](../../PLAN-NAPRAWY.md)
i [PLAN-PRODUKCJA.md](../../PLAN-PRODUKCJA.md).
